- [ ] **I. Free, Ad-Free, Private** (NON-NEGOTIABLE): no ads/IAP/paywall, no analytics/tracking/
      crash SDKs, no user-data network calls, no `INTERNET` permission unless justified, works offline
- [ ] **II. Correctness** (NON-NEGOTIABLE): every formula/reference value has a cited source;
      explicit units + SI prefixes; input validation with clear messages; precision/rounding rules defined
- [ ] **III. Simplicity**: each new dependency justified; no abstraction without ≥2 concrete uses;
      calculation/model/unit/reference code is pure Kotlin with no `android.*` imports
- [ ] **IV. Testability**: JVM unit tests for all calculation logic incl. edge cases and reference
      values, written test-first; logic-bearing UI (parsing, errors) tested
- [ ] **V. Localization**: no hardcoded strings; en/de/fr/es/ja/uk translations planned; locale-aware
      formatting; `.` and `,` accepted as decimal separators
- [ ] **VI. Version Control**: work on spec branch `###-feature-name`; merge only when tasks done and tests pass
- [ ] **VII. Distribution**: no Play Services/Billing/Core; no secrets or signing keys in the repo
